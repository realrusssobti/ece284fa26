\begin{center}
{\Large\bfseries Question 6: Batch Training versus SGD}\par
Observed behavior and explanation
\end{center}

\section*{Training conditions}
Both models start from weights $[1,-1]$ and train for 300 epochs with learning
rate $0.01$ and momentum $0.5$. Batch training updates once per epoch; SGD
updates after each point, with shuffled order using seed 0. This gives 300
batch updates and 900 SGD updates. Both comparison curves show full-data MSE
after each epoch.

\section*{Observed behavior}
With the same initialization and optimizer settings, batch training oscillates
initially, then settles near the minimum full-data MSE. Per-point SGD has a
much noisier curve, including large fluctuations late in training.
\begin{center}
\begin{tabular}{lrr}
\toprule
Method & Parameter updates & Final full-data MSE\\
\midrule
Batch gradient descent & 300 & 5.476191\\
Per-point SGD & 900 & 5.776175\\
\bottomrule
\end{tabular}
\end{center}
SGD's final loss is one point among
ongoing fluctuations, rather than evidence that its weights have settled.
During the last 50 epochs, its MSE ranged from approximately $5.523$ to $206.057$,
whereas the batch MSE remained approximately $5.476191$.

\section*{Why this happens}
Each sample pushes the weights toward a different solution. Here $x_2=3x_1$,
so the model is effectively
\[
\hat y=w_1x_1+w_2x_2=(w_1+3w_2)x_1=cx_1.
\]
The three input--target pairs require slopes $1$, $5/2$, and $13/3$.
No single slope fits all three exactly. Batch training averages their gradients
before each update, allowing it to settle at the best compromise. SGD uses one
sample's gradient, so improving that sample can worsen the other two. Shuffling
changes the order of these competing pushes.

The constant learning rate keeps SGD's updates from shrinking automatically.
Momentum carries earlier updates forward and can amplify overshooting.
Larger inputs also create larger gradients, since the sample gradient is
$2(\hat y-y)x$. Thus the loss fluctuations are caused by changes in the weights,
not merely by plotting a different sample's loss at each step.

The least-squares compromise is
\[
c=\frac{1(1)+2(5)+3(13)}{1^2+2^2+3^2}=\frac{25}{7},
\qquad L_{\min}=\frac{115}{21}\approx5.476190.
\]
Reducing or decaying SGD's learning rate would help it settle closer to this
compromise. It would not eliminate the model's inability to fit all three targets.
